Weather API Documentation

Overview

The Weather API provides real-time weather data for any location. Use this API to fetch current weather, forecasts, and historical data.

Base URL

https://http://127.0.0.1:5000/v1

Endpoints

1. Current Weather

Get the current weather for a specific location.

Endpoint: /station/date

Method: GET

Parameters:

  • station (string, required): Your API key.
  • date (string, required): Location (city name, zip code, or coordinates).

Example Request:

GET https://api.weatherapi.com/v1/station/date?key=YOUR_API_KEY&q=London
